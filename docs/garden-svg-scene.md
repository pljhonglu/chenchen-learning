# 混合绘本小花园

2026-10-04：依据 [同类项目调研](garden-growth-directions.md)，将首页从兔子握壶与位图拼接改为原创 SVG 植物养成；随后将非成长主体的环境替换为生成的绘本图片。Go 接口、成长账本、奖励条件和阶段算法保持不变。

## 绘制与动画

- `public/garden-scene.js` 将生成的水彩远山、草地、花丛作为整幅背景，透明云朵图片作为轻微漂移的环境层；枝干、叶片、花果、蝴蝶、小鸟与鸟窝继续使用矢量图形。图片均为本地 WebP，无远程依赖，也不使用兔子肢体或树木部件图集。每次挂载为矢量渐变分配独立 ID。
- 背景用独立 HTML 图片铺满场景，按容器居中裁切；树与云朵保留统一的 SVG 坐标系。手机端放大并下移植物构图，为标题留出空间。底部短句使用浅色半透明胶囊提高草地上的可读性。环境图片的加载不参与业务请求或成长时间线，加载失败时仍有渐变底色和完整植物。
- 固定根部坐标 `(365, 348)`。枝干形状由高度和弯曲量生成，叶柄起点沿主干定位，叶片始终从叶柄末端展开。调整叶片时不旋转整棵树或移动根部。成熟阶段的主干有渐细与根部过渡，枝条向左右分叉，大小错落的叶簇形成有空隙的树冠；同一数值模型把幼苗连续过渡到成年树形。
- GSAP 仅驱动数值模型，由统一绘制函数更新 SVG。水滴沿曲线落到根部，随后土地涟漪、茎部和叶片依次回应。普通照顾约 1.9 秒，里程碑约 2.75 秒；照顾动作不循环播放。
- 新叶从连接点展开；花苞过渡为逐瓣展开的花朵；青果通过颜色叠层渐变成熟。成熟后的蝴蝶、小鸟和鸟窝继续保留，嫩叶、花苞、花、果仍按原有阶段循环。
- 环境动态使用独立 GSAP ticker，最多约 30 次/秒更新：微风强弱缓慢变化，枝干、叶簇和单叶带有不同相位，花朵轻晃；成熟阶段蝴蝶绕行并扇翅、小鸟偶尔眨眼，透明云朵图片缓慢漂移。浇水期间暂停环境时钟，使用独立动作时间线，结束后恢复。
- 环境动态在每日照顾完成、滚动出视口、页面隐藏、减少动态效果和销毁时停止；回到可见区域后仅恢复一个订阅，不改变成长账本。
- 礼物图形改为 CSS 绘制，日历标题改为叶片装饰。原图集保留作历史资源，不在当前花园加载。

## 生命周期与业务边界

控制器继续提供 `mount()`、`setSnapshot()`、`playWater()`、`finish()`、`destroy()`。`garden.js` 保存与接收服务端结果后触发播放，礼物在视觉成长完成后显示。更新余额保留场景 DOM；一次只播放一个时间线。

切页、隐藏页面或切换减少动态效果时，清理时间线并显示最终已保存阶段。缺少 GSAP 时 SVG 仍完整绘制，保存与礼物继续工作；场景模块本身缺失时首页有内联静态幼苗及成长文字后备。

16 个阶段仍由实际浇水总数映射，每 12 滴变化一次，后期循环 12–15。每日发水与浇水限额、固定请求 ID 重试、成长礼物和日历继续沿用。

- 隔离预览中的 `scripts/test-garden-scene.browser.js`：12 项通过。包括第 3 次照顾播放完成、重复点击、真实屏幕坐标下的枝叶连接与根部稳定、花瓣展开、成年循环、导航与后台清理、丢响应幂等重试、缺少 GSAP 和全部 16 阶段及生成图片加载；另验证微风不移动树根或账本，以及离屏、后台、返回和销毁时的订阅清理。
- 浏览器实际开启 `prefers-reduced-motion`：108 滴正确进入蝴蝶阶段，礼物正常出现，没有活动时间线。
- 已在桌面与 390px 手机检查幼苗和开花构图，并检查浇水、花瓣展开的渲染帧。视觉检查与状态测试分别进行，测试通过不等于所有人都认可画风。
- 当前新增的运行时图片仅为背景与云朵，共 158,596 字节（约 155 KiB）。无额外动画库，GSAP 为现有本地依赖；未做真实手机性能跑分。原始 PNG、网页 WebP 和完整生成提示词均见 [素材说明](garden-painted-assets.md)。
